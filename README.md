# Ataque das Bruxas

Jogo de ação e aventura em que você controla Michel Rodrigues, um soldado que luta contra lobisomens e bruxas.

## Sobre o jogo
Michel Rodrigues é um soldado que precisa enfrentar lobisomens e bruxas para sobreviver. Derrote os inimigos e avance pelas fases.

## Desenvolvido com
[GDevelop](https://gdevelop.io), motor de jogos visual.

## Status
🚧 Em desenvolvimento

## Como jogar
1. Baixe o arquivo `gdevelop-game.zip` deste repositório.
2. Extraia o ZIP em uma pasta.
3. Abra o arquivo `index.html` no navegador.

## Controles
O jogo é controlado pelo teclado do computador.
(teclas de movimento e ataque em breve)

## Arquivos
- `gdevelop-game.zip`: jogo exportado
- `PACK ARTES JOGO GAMECRAFT.zip`: pacote de artes usado no jogo
